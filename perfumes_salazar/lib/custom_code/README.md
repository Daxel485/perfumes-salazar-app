# Custom code

Código Dart escrito por el equipo que luego se pega en FlutterFlow → *Custom Code*. Cada archivo entra por **pull request** (ver `CONTRIBUTING.md`).

| Carpeta | Contenido | Meta |
|---------|-----------|------|
| `widgets/` | Custom widgets (`StatefulWidget` con `width`/`height`) | ≥ 3 para la defensa |
| `actions/` | Custom actions (`Future<...>`) | |
| `functions/` | Custom functions (puras, sin `await`) | |

Asignación del Avance 3 en `docs/plan-avance-3.md`.
